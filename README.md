# One perfect orange

A single fresh orange half, cut face toward the viewer, macro-style on a
dark teal background — radial segments, juice vesicles, white pith ring, a
soft gloss highlight and juice beads on the rind. Rendered in pure Python
stdlib (no Pillow, no numpy): `main.py` draws every pixel and writes its own
PNG to `$MAKEFUN_OUTPUT_DIR/entry.png` (768×768).

## Run

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

Writes `./out/entry.png` (768×768, well under the 1 MiB gate).
